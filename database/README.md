# Database Architecture & Design (PostgreSQL + Prisma ORM)

This directory contains the production database design for the **11th & 12th Science Stream School Management System (SMS)** supporting:
- **4 Distinct Roles:** Student, Assistant Faculty, Subject Faculty, Principal
- **Academic Streams:** Group A (PCM - Physics, Chemistry, Mathematics) & Group B (PCB - Physics, Chemistry, Biology)
- **Exam Types:** Board (single-subject), JEE (PCM), NEET (PCB), GUJCET (PCM / PCB), Weekly, Monthly, and Annual Unit Exams
- **Interactive Workflows:** Daily Lecture Test (LT) cycle, Exam creation & grading, Result generation, Hall ticket generation, Syllabus progress, and Discipline remarks.

## 🚀 Setup & Execution Instructions

### 1. Configure PostgreSQL Connection
Create a `.env` file in your backend or project root:
```env
DATABASE_URL="postgresql://username:password@localhost:5432/sms_database?schema=public"
```

### 2. Generate Prisma Client
```bash
npx prisma generate --schema=database/schema/schema.prisma
```

### 3. Run Migrations
Push schema to your PostgreSQL database:
```bash
npx prisma db push --schema=database/schema/schema.prisma
```
*Or execute `database/migrations/001_initial_schema.sql` directly inside PostgreSQL.*

### 4. Seed the Database
```bash
node database/seeds/seed.js
```

## 🧩 Core Entities & Relationship Overview

| Model | Purpose | Key Relationships |
| :--- | :--- | :--- |
| `User` | Core authentication & role resolution | 1-to-1 with `Student`, `Faculty`, or `Principal` |
| `Student` | Student profile (Active & Alumni records) | Belongs to `User`; has `ltMarks`, `examMarks`, `resultItems`, `hallTickets` |
| `Faculty` | Subject Faculty & Assistant Faculty records | Belongs to `User`; links to `createdLTs`, `evaluatedLtMarks`, `createdExams`, `enteredExamMarks` |
| `Principal` | Administrative profile for school head | Belongs to `User`; manages broadcast `Notice` records |
| `Subject` | Master science & core subjects | Has many `Chapter` records & `LectureTest` records |
| `Chapter` & `Topic` | Granular syllabus hierarchy per standard | Topics link to `SyllabusCompletion` & `LtTopicCoverage` |
| `SyllabusCompletion` | Topics marked "Finished" today by Subject Faculty | Drives "Today's Finished Topic List" for LT and Syllabus Tracking meters |
| `LectureTest` (LT) | Daily tests created by Subject Faculty | Created by `Faculty`; has many `LtTopicCoverage` & `LtMarkEntry` |
| `LtMarkEntry` | Grades evaluated by Assistant Faculty (`Excellent`, `Better`, `Good`, `AB`) | Links `LectureTest`, `Student`, and evaluator `Faculty`; flags `isWeakTopic` |
| `Exam` | Exams created from Exam Unit tab (Board, JEE, NEET, GUJCET) | Created by Subject `Faculty`; conducted by Assistant `Faculty` |
| `ExamMarkEntry` | Student scores (single or multi-subject PCM/PCB) | Stores `physicsScore`, `chemistryScore`, `mathsScore`, `biologyScore`, `totalScore`, `percentile` |
| `ResultBatch` & `ResultItem` | Auto-generated batch result sheets | Generated by Assistant `Faculty`; holds calculated student totals, ranks, percentages |
| `HallTicketBatch` & `HallTicket` | Generated exam hall tickets with seat numbers | Generated by Assistant `Faculty`; individual seat allocation per `Student` |
| `DisciplineRemark` | Incidents logged by school staff | Logged by `Faculty` for a `Student` with type (`COME_LATE`, `LONG_HAIR`, etc.) |
| `ProgressReport` | Pre-calculated weekly/monthly student trends | Student rank, growth rate, weak topic list, and radar benchmarks |
